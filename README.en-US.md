# BBKGames_GameShell
BBKGames Classic Games Ported to GameShell

Original Project: https://github.com/cyanzhong/bbk.emu

Thanks to 孤獨愛你 for providing icon resources. For more resources, join the QQ group: 1041399424

## One-Click Installation Script

After connecting to GameShell via SSH, execute the following command:

```bash
bash <(curl -s https://raw.fastgit.org/zzxzzk115/BBKGames_GameShell/main/install.sh)
```
